## Golden Clean Architectural Reference Targets (`G01`–`G02`)

| Code | Target | Reference Image | Rule |
| :--- | :--- | :--- | :--- |
| **G01** | Clean Hollow Wall Pipeline | `golden/G01_clean_wall_pipeline.png` | Hollow double-skin walls, floors, and ceilings must be 100% clean inside like continuous pipelines connecting to columns — zero trapped shards, fins, reversed faces, or flicker trash inside cavities. |
| **G02** | Solid Unbroken Column Junction | `golden/G02_solid_column_junction.png` | Structural columns stay 100% solid and unbroken where walls connect (`protect_coplanar_patches` + `restore_visible_surfaces`); clean the wall cavity without breaking column faces. |
